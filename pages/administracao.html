Fonte de dados

IndexedDB (local) Supabase

Define qual banco o sistema usa no dia a dia (dashboard, cadastros, relatórios). Ao importar uma planilha, os registros são sempre gravados nos dois bancos — IndexedDB e Supabase — independentemente da opção escolhida aqui, para que os dois fiquem sincronizados enquanto o Supabase estiver em teste.

Encontre esses valores em Project Settings → API no painel do Supabase. Ficam salvos só neste navegador (localStorage) — não vão para o repositório do projeto.
